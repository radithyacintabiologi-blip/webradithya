HTML

HTML (HyperText Markup Language) adalah bahasa markup standar untuk membuat struktur dan konten halaman web, menggunakan kode atau tag untuk mengatur elemen seperti teks, gambar, tautan, dan video agar bisa ditampilkan oleh browser web

CSS

CSS (Cascading Style Sheets) adalah bahasa stylesheet untuk mengatur tampilan dan gaya elemen halaman web (seperti warna, font, tata letak, dan ukuran), memisahkan konten (HTML) dari presentasinya agar website lebih menarik, konsisten, dan mudah dikelola, dengan satu file CSS bisa diterapkan ke banyak halaman HTML. Tanpa CSS, halaman web hanya teks polos; CSS ibarat "make-up" yang membuat kerangka HTML terlihat indah.
